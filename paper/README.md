# Overleaf draft

Upload `main.tex` and `references.bib` to a new Overleaf project. The draft is
deliberately conservative: it includes only verified storage and correctness
findings, and marks missing adjacency-list, energy, and final benchmark results
with `TODO` text.

Compile with pdfLaTeX. The project does not require external figure files yet.
Before submission:

1. Replace every `TODO` with measured results or a clearly stated limitation.
2. Add the full authorship, affiliations, acknowledgements, and code URL.
3. Add figures generated from the final benchmark CSV.
4. Verify every numerical claim against a committed result artifact.
5. Run a final spelling, citation, and reproducibility review with the
   professor and all coauthors.
